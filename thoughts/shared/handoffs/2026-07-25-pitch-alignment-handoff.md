### One real gap found, deliberately NOT fixed

**Archivo is never loaded.** `design/brand/tokens.css` declares
`--goods-font-logo: "Archivo", "Helvetica Neue", Arial, sans-serif`, but `src/app/layout.tsx` loads
only Inter, Playfair Display and Poppins via `next/font/google`. Archivo silently falls back to
Helvetica.

Blast radius is small today: `--goods-font-logo` is consumed only by
`design/brand/cards/typography.html` (a brand card, not the app), and every app-facing logo is an
image, so nothing user-visible is wrong. But that card renders the wordmark in the wrong typeface,
and any future surface setting the mark as text would be off-brand.

Left alone on purpose: adding a font to `layout.tsx` would edit a file that session has in flight.
**Whoever owns the brand work should decide** whether to load Archivo via `next/font/google` or drop
the variable. Note the separate pre-existing mismatch: CLAUDE.md and `tokens.css` both say the
display face is Georgia, while the app actually loads Playfair Display.

### What this changed in the deck

approved kit. All 12 slides now carry the real
`goods-on-country-grounded-primary.svg`. **Do not set the mark as text.**
