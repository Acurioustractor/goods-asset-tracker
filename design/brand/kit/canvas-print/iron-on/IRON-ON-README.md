Notes
- Code points at https://www.goodsoncountry.com/ and was decode-tested composited on ink (inverted), 1400/700/420 px.
- HTV: rounded squares, not dots, so the weeding is 400 pieces instead of 500 tiny circles. Still a job. Ask the shop to weed it.
- The SVG text "Designed on Country" is live text in Helvetica Bold. Convert to outlines in the cutter software (Cricut/Silhouette/Illustrator) before cutting, or send the PNG and let the shop trace it.
- The black square in the cut SVG marks the badge area; delete it before cutting. It is only there so the text sits on a visible box in preview.
- Cotton duck: press at 150 to 160 C for 15 s medium pressure, peel per the film's instructions, test one cover first and wash it before committing to 200.
- Keep 60 mm clear of each sleeve seam; the foot-end block is logo 500 mm wide, then a 30 mm gap, then the 200 mm code, then the caption.
